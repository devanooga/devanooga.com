We run a XenForo instance at **[forums.devanooga.com](https://forums.devanooga.com/)** for longer-form discussion that doesn&rsquo;t fit in a Slack channel: project show-and-tells, job postings worth keeping searchable, technical write-ups, community planning.

## Signing up

Forum registration is gated by an invite code we rotate in Slack so we can keep spam down. To get it:

1. [Join our Slack](/slack/) if you haven&rsquo;t already.
2. Open the **`#devanooga-meta`** channel. The current registration code is posted in the channel topic.

Already registered? Head straight to **[forums.devanooga.com](https://forums.devanooga.com/)**.
